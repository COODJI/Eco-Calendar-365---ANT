# 🌱 Eco Calendar 365

**365 actions écologiques quotidiennes pour transformer vos habitudes et sauver la planète, un jour à la fois.**

![Eco Calendar 365](https://img.shields.io/badge/version-1.0.0-green) ![License](https://img.shields.io/badge/license-MIT-blue)

---

## 📖 À propos

**Eco Calendar 365** est un calendrier écologique digital interactif qui propose chaque jour une action concrète, simple et mesurable pour réduire votre empreinte environnementale. Inspiré du principe du calendrier de l'avent, mais étendu sur toute l'année.

### 🎯 Objectifs

- **Éduquer** : Sensibiliser aux enjeux environnementaux avec des données scientifiques
- **Motiver** : Gamifier l'écologie pour créer des habitudes durables
- **Mesurer** : Quantifier l'impact réel de chaque action (CO₂, eau, économies)
- **Rassembler** : Créer une communauté d'éco-citoyens engagés

---

## ✨ Fonctionnalités

### 📅 12 Thèmes Mensuels

Chaque mois explore un aspect de l'écologie :

1. **Janvier** - ⚡ Énergie & Chauffage
2. **Février** - 💧 Eau & Ressources
3. **Mars** - ♻️ Déchets & Recyclage
4. **Avril** - 🌱 Biodiversité & Jardinage
5. **Mai** - 🚴 Mobilité Douce
6. **Juin** - ☀️ Énergie Solaire
7. **Juillet** - 🌊 Océans & Plages
8. **Août** - 🦋 Biodiversité Sauvage
9. **Septembre** - 🍎 Alimentation Durable
10. **Octobre** - 🏠 Habitat & Isolation
11. **Novembre** - 🌫️ Qualité de l'Air
12. **Décembre** - 🎁 Consommation Responsable

### 🎮 Gamification

- **Système de progression** : Suivez vos actions réalisées
- **Streak** : Maintenez votre série de jours consécutifs
- **Badges** : Débloquez des récompenses (Premier Pas, Semaine Verte, Champion Mensuel, etc.)
- **Impact mesuré** : Visualisez votre contribution (CO₂ évité, eau économisée, argent économisé)

### 📊 Chaque Action Contient

- ✅ **Action concrète** : Geste simple et réalisable
- 💡 **Explication** : Pourquoi c'est important
- 📈 **Impact mesurable** : CO₂, eau, économies
- 📚 **Fait scientifique** : Anecdote ou chiffre clé
- 🔗 **Source fiable** : ADEME, GIEC, ONU Environnement
- 💡 **Astuces bonus** : Conseils pratiques

## 🚀 Installation

### Prérequis

- Navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Aucune installation requise !

### Utilisation

1. **Téléchargez** ou clonez ce repository
2. **Ouvrez** le fichier `index.html` dans votre navigateur

## 🎯 Exemples d'Actions

### Janvier - Énergie

- **Jour 1** : Éteignez les lumières en sortant (-150 kg CO₂/an)
- **Jour 2** : Débranchez les appareils en veille (-200 kg CO₂/an)
- **Jour 3** : Baissez le chauffage de 1°C (-300 kg CO₂/an)

### Février - Eau

- **Jour 1** : Réduisez votre douche de 2 minutes (-7300 L/an)
- **Jour 2** : Fermez le robinet en vous brossant les dents
- **Jour 3** : Installez un pommeau de douche économe

## 💾 Sauvegarde des Données

Vos progrès sont automatiquement sauvegardés dans le **localStorage** de votre navigateur :

- Actions complétées
- Streak actuel
- Impact total (CO₂, eau, économies)
- Badges débloqués

**Note** : Les données restent sur votre appareil. Aucune donnée n'est envoyée à un serveur.

## 🤝 Contribution

Les contributions sont les bienvenues ! Voici comment participer :

### Ajouter des Actions

1. Éditez `js/data.js`
2. Ajoutez votre action dans le tableau `ACTIONS`
3. Respectez la structure :

```javascript
{
    id: 365,
    day: 31,
    month: 12,
    theme: "consumption",
    icon: "🎁",
    title: "Votre action",
    description: "Description détaillée",
    why: "Pourquoi c'est important",
    impact: { co2: 100, unit: "kg/an", savings: 50 },
    fact: "Fait scientifique",
    source: "ADEME, 2024",
    sourceUrl: "https://www.ademe.fr",
    difficulty: "facile",
    duration: "5 min",
    tips: ["Astuce 1", "Astuce 2"]
}
```

### Améliorer le Design

1. Éditez `styles/main.css`
2. Respectez les variables CSS existantes
3. Testez sur mobile et desktop

### Corriger des Bugs

1. Ouvrez une issue sur GitHub
2. Décrivez le problème
3. Proposez une solution si possible
