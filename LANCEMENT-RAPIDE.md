# 🚀 DÉPLOIEMENT RAPIDE

## Exécutez simplement ce script :

```powershell
cd c:\Users\willi\Downloads\STITCH\eco-calendar-365
.\deploy-to-github.ps1
```

Ce script va automatiquement :
1. ✅ Créer les dossiers `assets/themes/` et `assets/icons/`
2. ✅ Copier les 12 images thématiques
3. ✅ Initialiser Git
4. ✅ Ajouter et commiter tous les fichiers
5. ✅ Pousser vers votre dépôt GitHub

## Après l'exécution du script :

1. Allez sur https://github.com/COODJI/Eco-Calendar-365---ANT
2. Cliquez sur **Settings** → **Pages**
3. Sous "Source", sélectionnez :
   - Branch : `main`
   - Folder : `/ (root)`
4. Cliquez sur **Save**

## Votre application sera en ligne à :
```
https://coodji.github.io/Eco-Calendar-365---ANT/
```

⏱️ Attendez 1-2 minutes après l'activation de GitHub Pages.
